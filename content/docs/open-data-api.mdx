# Open Data API

The Open Data API provides **public, read-only** endpoints for discovery and transparency — no client credentials required for published reference data.

## Typical capabilities

- Code lists and reference values
- Conformance / profile metadata
- Participant and software discovery summaries
- Aggregated published price data (supporting fee-comparison style tools)

## Example use

Mattertwo&apos;s **FeeFinder** demo compares published prices using open data only — illustrating transparency without a full consent journey.

## Spec & hosts

- Repository: [openlawuk/open-data-api](https://github.com/openlawuk/open-data-api)
- Planned host: `opendata.openlaw.org.uk`
- Sandbox examples may use `opendata.sandbox.openlaw.org.uk`
