# Conformance

The Open Law Conformance Suite is a **CLI** that helps TSPs and implementers prove they behave safely for the open marketplace.

## What it covers

- Directory interactions
- Dynamic Client Registration
- Authorisation / FAPI hygiene
- **Client data boundaries** — ensuring TSPs only return data the client is entitled to see

## Why boundaries matter

An open marketplace only works if a compromised or overly broad TPP cannot see another client&apos;s matters. Boundary checks are part of the safety story for regulators and firms.

## Get the suite

[openlawuk/conformance-suite](https://github.com/openlawuk/conformance-suite) — run against your TSP or the reference implementation and retain attestation evidence for your release process.
