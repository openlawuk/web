# Standards roadmap for 2026

Open Law's normative specifications live in the public GitHub organisation. This year we're focused on stabilising the core stack so implementers can build with confidence.

## Near-term priorities

1. **Directory** — participant registration, JWKS, and Software Statement Assertions
2. **Dynamic Client Registration** — RFC 7591/7592 profile for firm TSP onboarding
3. **Read/Write API** — FAPI 2.0 resource APIs with client consent flows
4. **Conformance suite** — CLI coverage for directory, DCR, auth hygiene, and client data boundaries

## How to follow along

Track releases in the [specification repository](https://github.com/openlawuk/specification). For hands-on work, start with the [reference TSP](https://github.com/openlawuk/reference-tsp) and the getting started guide on this site.
